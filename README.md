# Primo Plumbing Website

This folder contains a complete one-page HTML website for Primo Plumbing.

## Files
- `index.html` — the full website code
- `assets/primo-plumbing-logo.jpeg` — the Primo Plumbing logo image

## How to put this on GitHub Pages

1. Go to https://github.com and log in.
2. Click the + button in the top right.
3. Click **New repository**.
4. Name it something like `primo-plumbing-site`.
5. Make it **Public**.
6. Click **Create repository**.
7. Click **uploading an existing file**.
8. Drag the contents of this folder into GitHub:
   - `index.html`
   - the `assets` folder
   - `README.md`
9. Click **Commit changes**.
10. Go to **Settings**.
11. Click **Pages**.
12. Under **Build and deployment**, choose:
    - Source: **Deploy from a branch**
    - Branch: **main**
    - Folder: **/root**
13. Click **Save**.
14. Wait a minute, then GitHub will show your website link.
